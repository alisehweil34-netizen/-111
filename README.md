# نظام الامتحانات الإلكترونية — نسخة محلية بالكامل

هذه النسخة لا تستخدم Firebase أو أي خدمة Backend أو API خارجي.

## التخزين
- بيانات الأستاذ والامتحانات والأسئلة وإجابات الطلاب والنتائج والمخالفات تُحفظ في `localStorage` داخل المتصفح.
- تسجيل دخول الأستاذ عبر Firebase Authentication (البريد وكلمة المرور تُنشأ من لوحة Firebase ولا تُكتب في أي ملف) — انظر SETUP.md.
- الطلاب يدخلون بالاسم ورمز الامتحان، وتُحفظ بياناتهم محليًا في نفس المتصفح.

## تشغيل الموقع
يمكن فتح `index.html` مباشرة، أو نشر الملفات كما هي على GitHub Pages.

## تنبيه مهم (انظر SETUP.md لحل مشكلة تعدد الأجهزة)
لأن النظام محلي بالكامل ولا يوجد خادم، فإن البيانات ليست مشتركة بين أجهزة مختلفة. إذا دخل الأستاذ من جهاز والطالب من جهاز آخر، فلن يرى كل منهما بيانات الآخر. هذه النسخة مناسبة للاستخدام المحلي/التجريبي، وليست قاعدة بيانات سحابية متعددة الأجهزة.

## كتابة الأسئلة دفعة واحدة
من صفحة تعديل الامتحان اضغط «كتابة عدة أسئلة دفعة واحدة». افصل بين الأسئلة بسطر فارغ:

```
What is the capital of France?
A) Berlin
B) Paris *
C) Madrid
D) Rome
Points: 2

The sun rises in the west.
TF: false

Write the past tense of "go".
Answer: went, Went

Write a short paragraph about your daily routine.
Essay
Points: 5
```
- اختيار من متعدد: أربعة اختيارات A–D، والصحيح بعلامة `*` أو سطر `Answer: B`.
- صح/خطأ: `TF: true` أو `TF: false`.
- إجابة قصيرة: `Answer:` والإجابات المقبولة مفصولة بفاصلة.
- مقالي: سطر `Essay`.
- الدرجة اختيارية `Points: 2` (الافتراضي 1).

## مراقبة الغش ومنع إعادة الدخول
- **تعليمات قبل الدخول:** صفحة دخول الطالب تعرض تعليمات واضحة (أن أي خروج من الامتحان يُسجَّل كمحاولة غش، وأن الدخول بعد التسليم ممنوع حتى لو تغيّر الاسم) ولا يُفعَّل زر الدخول إلا بعد موافقة الطالب.
- **ما الذي يُسجَّل:** تبديل التبويب/التطبيق، تصغير المتصفح أو فقدان التركيز (مرة واحدة لكل خروج مع **مدة الغياب**)، محاولة إغلاق الصفحة أو تحديثها، **العودة للامتحان بعد مغادرته** (`RE_ENTRY`)، النسخ/اللصق/الزر الأيمن، اختصارات أدوات المطوّر.
- **للأستاذ:** في صفحة النتائج عمود «المخالفات»، وعند فتح طالب يظهر **سجل المخالفات** بالتفصيل (النوع، الوقت بالثواني، مدة الغياب).
- **منع الدخول بعد التسليم:** المحاولة مرتبطة بـ«معرّف الجهاز» وليس بالاسم، ويُحفظ المعرّف في localStorage وCookie وIndexedDB معًا (مسح واحد منها لا يكفي لإخفائه). أي محاولة دخول بعد التسليم تُرفض وتُسجَّل في سجل الطالب مع الاسم الذي أُدخل.
- **حدّ معروف:** مسح بيانات المتصفح بالكامل أو استخدام متصفح/جهاز آخر أو وضع التصفح الخاص يعطي هوية جديدة، ولا يمكن منع ذلك بدون خادم أو أكواد فردية لكل طالب.
